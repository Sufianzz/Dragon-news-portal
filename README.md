# 📰 Dragon News Portal

A dynamic and modern news application built with **Next.js**, providing real-time updates and seamless category-based news navigation.

---

## 🔗 Live Links

- **Live Site:** [Dragon News Portal](https://dragon-news-web-7fl9.vercel.app/category/01)
- **GitHub Repository:** [Dragon-news-portal](https://github.com/Sufianzz/Dragon-news-portal)

---


## ✨ Features

- **Category-based Filtering:** Easily browse news articles by specific categories.
- **Responsive Design:** Optimized for mobile, tablet, and desktop viewports.
- **Fast Performance:** Server-Side Rendering (SSR) & Static Site Generation (SSG) powered by Next.js.
- **Clean UI:** Intuitive and interactive user interface for smooth reading experience.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Library:** [React](https://react.dev/)
- **Deployment:** [Vercel](https://vercel.com/)
- **Styling:** CSS / Tailwind CSS
